# Tara Geomatics website

Static site — no build step.

```
index.html
css/style.css
js/main.js
```

Preview locally: `python3 -m http.server` then open http://localhost:8000

Deploy on GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

Placeholders to replace before launch: stats, case studies, services/industries/tech lists (arrays in `js/main.js`), and contact details in `index.html`.
